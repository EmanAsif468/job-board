# Job Board API

A simple REST API for posting and managing jobs, built while learning full-stack development.

## Tech Stack
- Node.js
- Express
- PostgreSQL

## Features
- List all jobs
- Get a single job
- Create, update and delete jobs

## Run locally
1. Install dependencies: `npm install`
2. Create a `.env` file with your database settings
3. Start the server: `npm run dev`
